# 复杂度(Complexity)

## 时间复杂度（Time Complexity）

### 1. 定义

时间复杂度是衡量算法执行所需 时间随输入规模增长而增长的速度。它反映了算法效率的上界，而不是具体执行时间（具体时间会受硬件、语言等影响）。

公式上可以理解为：

```js
𝑇(𝑛)=𝑂(𝑓(𝑛))
```

- n = 输入规模（比如数组长度、节点数）

- f(n) = 描述算法执行步骤数量的函数

- O(f(n)) = 算法在最坏情况下的增长量级（大 O 表示法）

### 2. 常见时间复杂度

| 时间复杂度 | 描述                           | 典型例子                    |
| ---------- | ------------------------------ | --------------------------- |
| O(1)       | 常数时间，不随输入规模变化     | 数组访问 arr[i]、哈希表查找 |
| O(log n)   | 对数时间，每次规模缩小一半     | 二分查找、平衡二叉树查找    |
| O(n)       | 线性时间，执行次数和输入成正比 | 遍历数组、简单求和          |
| O(n log n) | 线性对数时间                   | 快速排序、归并排序          |
| O(n²)      | 平方时间                       | 嵌套两层循环、冒泡排序      |
| O(2^n)     | 指数时间                       | 递归求斐波那契（普通递归）  |
| O(n!)      | 阶乘时间                       | 全排列、旅行商问题暴力解    |

### 3. 如何分析时间复杂度

方法：按语句计数

1. 找出算法的主要循环或递归。
2. 计算基本操作执行次数。
3. 保留最高阶项，忽略低阶和常数。

- 例子1：单循环

```js
for (let i = 0; i < n; i++) {
  console.log(i);
}
//执行次数 = n
//时间复杂度 = O(n)
```

- 例子2：嵌套循环

```js
for (let i = 0; i < n; i++) {
  for (let j = 0; j < n; j++) {
    console.log(i, j);
  }
}

//内层循环执行 n 次，外层循环也 n 次
//总执行次数 = n * n = n²
//时间复杂度 = O(n²)
```

- 例子3：递归

```js
function fib(n) {
  if (n <= 1) return n;
  return fib(n - 1) + fib(n - 2);
}
//递归树大小 ≈ 2^n
//时间复杂度 = O(2^n)
```

### 4. 小技巧

- 循环嵌套 → 乘法规则
- 连续循环 → 加法规则
- 常数操作 → 忽略
- 递归 → 画递归树或用主定理分析

## 空间复杂度（Space Complexity）

### 1. 定义

空间复杂度是衡量算法在执行过程中 占用内存空间随输入规模增长而增长的速度。

公式：

```js
S(n)=O(f(n))
```

- 包括：输入数据、辅助变量、递归栈

- 和时间复杂度类似，分析的核心是输入规模 n 如何影响占用空间

### 2. 常见空间复杂度

| 空间复杂度 | 描述     | 例子                       |
| ---------- | -------- | -------------------------- |
| O(1)       | 常数空间 | 变量、指针                 |
| O(n)       | 线性空间 | 复制数组、链表、递归深度 n |
| O(n²)      | 二维数组 | 矩阵操作                   |
| O(log n)   | 对数空间 | 平衡二叉树递归深度         |

### 3. 空间复杂度分析方法

1. 变量占用：简单的 int、float、bool → O(1)
2. 数组/对象占用：大小 n → O(n)
3. 递归调用栈：深度 d → O(d)
4. 辅助数据结构：hash map、stack → 按大小计算

- 例子1：迭代求和

```js
let sum = 0;
for (let i = 0; i < n; i++) {
  sum += i;
}

//变量 sum → O(1)
//循环索引 i → O(1)
//总空间复杂度 = O(1)
```

- 例子2：递归斐波那契

```js
function fib(n) {
  if (n <= 1) return n;
  return fib(n - 1) + fib(n - 2);
}

//每次递归都压栈
//栈深度 = n → O(n)
//实际存储结果的空间 = O(1)（如果不存结果）
```

- 例子3：存储数组

```js
let arr = new Array(n).fill(0);

//占用空间 = n → O(n)
```

### 4. 小技巧

1. 递归 → 注意栈深度
2. 动态规划 → 通常可以用滚动数组优化空间
3. 不改变原数组 → 空间复杂度可能高
4. 原地操作 → 常数空间

## 对比

时间复杂度 vs 空间复杂度

| 方面     | 时间复杂度         | 空间复杂度                 |
| -------- | ------------------ | -------------------------- |
| 关注     | 执行速度           | 内存占用                   |
| 分析     | 循环次数、递归次数 | 变量、数组、栈深度         |
| 优化方向 | 减少计算、避免重复 | 减少额外数据结构、原地算法 |

💡 提示：很多算法有“空间换时间”策略，例如：

- 哈希表快速查找 → 用额外 O(n) 空间减少 O(n²) 时间
- DP 缓存递归结果 → 用 O(n) 空间减少 O(2^n) 时间
