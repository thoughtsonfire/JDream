# 创建项目

## 写demo

> 自己建文件夹后，用 IntelliJ IDEA 打开，这种是练习demo最轻便的

> [!TIP]✔ 必须
>
> - 配置 JDK（Project SDK）
> - 标记源码目录（Sources Root）

> 🚀 在 IDEA 里怎么操作
>
> 方法一：直接打开文件夹
> 打开 IntelliJ IDEA
> 点 Open
> 选择你的文件夹
>
> 方法二：如果运行不了（常见）
>
> 👉 手动配置一下：
>
> ✔ 设置 JDK
> File → Project Structure  
> 设置：  
> Project SDK = 你的 OpenJDK 或 Oracle JDK
>
> ✔ 标记目录
>
> 如果你后面会写多个文件：
>
> 右键文件夹 → Mark Directory as → Sources Root
> 🧠 判断成功的标志
>
> 👉 你会看到：
>
> 类名左边出现 ▶ 按钮
> 右键有 Run 选项
